### Границы сервиса

**Входит:** приём bid request; определение пользователя; подбор кандидатов по таргетингу; применение бизнес-правил и проведение аукциона; формирование bid response; уведомления о выигрыше (win notice).

**Не входит:** формирование и выдача артефакта рекламы пользователю (Delivery); приём и обработка показов и кликов (Events); списания и балансы (Billing); создание и редактирование кампаний (Campaign/монолит); аутентификация партнёров и ограничение частоты (API Gateway).

**Основание границы:** обязательство отвечать в пределах 80 ms относится ко всему пути от запроса партнёра до ответа. Сервис владеет этим путём целиком — иначе ответственность за требование размывается между компонентами.

### API

openapi: 3.0.3
info:
  title: AdScale Bidding API (OpenRTB 2.6)
  version: 1.0.0
paths:
  /openrtb/2.6/bid:
    post:
      summary: Запрос ставки от DSP-партнёра
      requestBody:
        required: true
        content:
          application/json:
            schema:
              type: object
              required: [id, imp, tmax]
              properties:
                id:
                  type: string
                  description: Идентификатор аукциона
                  example: "1e5f8a2c-7b19"
                tmax:
                  type: integer
                  description: Бюджет времени на ответ, мс
                  example: 80
                imp:
                  type: array
                  description: Рекламные места
                  items:
                    type: object
                    properties:
                      id: { type: string, example: "1" }
                      w: { type: integer, example: 300 }
                      h: { type: integer, example: 250 }
                      bidfloor:
                        type: number
                        description: Минимальная цена, CPM
                        example: 0.15
                device:
                  type: object
                  properties:
                    devicetype: { type: integer, example: 2 }
                    geo:
                      type: object
                      properties:
                        country: { type: string, example: RUS }
      responses:
        '200':
          description: Ставка сформирована
          content:
            application/json:
              schema:
                type: object
                properties:
                  id: { type: string, description: Копия id запроса }
                  seatbid:
                    type: array
                    items:
                      type: object
                      properties:
                        bid:
                          type: array
                          items:
                            type: object
                            properties:
                              impid: { type: string, example: "1" }
                              price: { type: number, example: 0.42 }
                              cid: { type: string, example: "10482" }
                              crid: { type: string, example: "cr-3" }
                              nurl:
                                type: string
                                description: Адрес уведомления о выигрыше
        '204':
          description: |
            Отказ от участия (no-bid): нет кандидатов, исчерпана квота
            бюджета или истёк tmax. Канонический ответ OpenRTB, тела нет
        '401':
          description: Партнёр не аутентифицирован
        '429':
          description: Превышен лимит частоты запросов

  /openrtb/2.6/win:
    get:
      summary: Уведомление о выигрыше аукциона
      parameters:
        - name: auction_id
          in: query
          required: true
          schema: { type: string }
        - name: price
          in: query
          required: true
          schema: { type: number, example: 0.42 }
      responses:
        '200':
          description: |
            Принято. Операция идемпотентна: повторный вызов с тем же
            auction_id возвращает 200 и не списывает квоту повторно

  /health/ready:
    get:
      summary: Готовность принимать трафик (снапшот кампаний прогрет)
      responses:
        '200': { description: Готов }
        '503': { description: Прогрев не завершён }


### Зависимости

| Зависимость                      | Способ                                                                                               | В горячем пути            | Поведение при недоступности                                               |
| -------------------------------- | ---------------------------------------------------------------------------------------------------- | ------------------------- | ------------------------------------------------------------------------- |
| Campaign Service                 | логическая репликация PostgreSQL → снапшот (через 3 месяца); <br>в целевом состоянии — поток событий | нет                       | работает на последнем снапшоте; растёт метрика его возраста               |
| Billing — квоты бюджета          | Redis, атомарное уменьшение                                                                          | да, один вызов на выигрыш | локальный резерв квоты; по исчерпании — no-bid по кампании                |
| Redis — счётчики частоты показов | Redis                                                                                                | да, один вызов            | ограничение частоты не применяется (сознательная деградация)              |
| Events / Kafka                   | публикация событий асинхронно                                                                        | нет                       | буфер в памяти с последующей досылкой; при переполнении — сброс с алертом |
Ни одного синхронного вызова в монолит в hot path или  кдругим сервисам в сервисной архитектуре.


### Модель данных 

| Название объекта               | Система                           | Комментарии                                                                                                                 |
| ------------------------------ | --------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Кампания, настройки таргетинга | Campaign (сейчас — монолит)       | Только чтение. Копия целиком в памяти процесса, обновляется логической репликацией. В горячем пути обращений к БД нет       |
| Креатив                        | Campaign (сейчас — монолит)       | Только чтение, в составе того же снапшота. Bidding возвращает идентификатор креатива, разметку формирует Delivery           |
| Квота бюджета                  | Billing выдаёт, Bidding расходует | Redis, атомарное уменьшение. Перерасход ограничен размером выданной квоты                                                   |
| Счётчик частоты показов        | Bidding                           | Redis, общий для всех экземпляров, TTL сутки                                                                                |
| Аукцион                        | Bidding                           | Владелец. Журнал: кандидаты, причины отсечения, победитель, цена. Ограниченный срок хранения — содержит персональные данные |
| Ставка                         | Bidding                           | Владелец. Кампания, креатив, цена в рамках аукциона                                                                         |
| Выигрыш аукциона               | Bidding                           | Владелец. Фиксируется по уведомлению партнёра, публикуется событием `AuctionWon` для Events и Billing                       |
